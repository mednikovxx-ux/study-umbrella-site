# Study Umbrella — сайт и личный кабинет

Онлайн-школа: иностранные языки (английский, испанский, итальянский, китайский, корейский, турецкий)
и подготовка к ОГЭ/ЕГЭ (история, обществознание, русский язык). Владелец — Валерия.
Общение с владельцем — на русском, простыми словами, без технического жаргона.

## Структура

- `site/` — готовый сайт, его и выкладываем на хостинг. Не править руками внутренние страницы — они собираются.
  - `site/index.html` — главная, правится напрямую (из неё же берутся шапка, подвал, форма заявки и карточки преподавателей для остальных страниц).
  - `site/css/main.css`, `site/js/main.js` — общие стили и скрипты.
  - `site/fonts/` — шрифты лежат на сайте (не Google Fonts: скорость и 152-ФЗ).
- `src/pages/*.html` — исходники внутренних страниц (`<!--HEAD-->` мета + `<!--BODY-->` содержимое).
  Вставки: `{{CTA}}` (блок заявки), `{{TEACHERS:Имя|Имя}}`, `{{ALLTEACHERS}}`, `{{ICON:lucide-имя}}`, `{{FLAG:gb|es|it|cn|kr|tr}}`.
  `blog__slug.html` → `site/blog/slug/`.
- `src/lk/` — личный кабинет (React). `app.jsx` — система управления школой владельца (исходник в `reference/original-system.jsx`), адаптированная: бренд, цены сайта, итальянский/турецкий, банки тем ОГЭ/ЕГЭ для гуманитарных предметов, вход.
  - `main.jsx` — экран входа (Telegram / телефон+код / почта, регистрация) и запуск.
  - `access.js` — проверка ролей; контакты ВЛАДЕЛЬЦА и закреплённых админов — в `owner.local.js` (не в git, шаблон `owner.example.js`). `site/lk/app.js` тоже не в git: собирать `npm run build`. Роль «администратор» есть только у владельца и тех, кому он выдал доступ в кабинете («Администраторы»).
  - `extras.jsx` — общая библиотека материалов по предметам (su-library-v1; правят преподаватели предмета и админ, ученик только смотрит), сводка «Мой прогресс» ученика, вызов администратора (su-calls-v1), запросы на оплату new→link_sent→paid→confirmed (su-payreq-v1; подтверждение добавляет занятия к остатку пакета и пишет продажу), смайлы и реакции в чате. Форматы ученика (`format`: individual / self «Сам, но не один» / umbrella «Под одним зонтом» — вторая карточка `umbrellaWith`, общий пакет / pair / group), пары и группы с постоянным расписанием (su-groups-v1, занятия ставятся каждому участнику с `groupId`), программа по уровням (`level` у темы), диаграммы прогресса и траектория к экзамену (SVG), «Занятия» ученика: оплата урока не позже чем за 12 ч (ссылка только после оплаты или из пакета), перенос/отмена до 4 ч.
  - `storage.js` — хранилище: сейчас браузер (демо), заменить на API сервера.
- `tools/` — сборка. `reference/` — исходная система, брендбук, исходный шрифт.

## Команды

- `npm install` — один раз.
- `npm run build` — собрать страницы и кабинет.
- `npm start` — открыть сайт локально: http://localhost:8080

- `tools/publish_pages.sh` — обновить демо на GitHub Pages (ветка gh-pages): https://mednikovxx-ux.github.io/study-umbrella-site/ — запускать после изменений. Вход администратора в демо не работает (контактов владельца там нет).

## Бренд

Шрифты: Kyiv*Type Serif Bold — заголовки (© Dmitry Rastvortsev, бесплатный), Onest — текст, Caveat — рукописные пометки (одна на экран), Poppins — только логотип (нет кириллицы).
Цвета сайта: бумага #F5F0E8, графит #1E2B2F, красный #D65655 (кнопки #B8303C), бирюза #2F6F73, масло #F3D27A, лиловый #D9C8E8, небо #C9DCF7. Брендбук: `reference/Study_Umbrella_brandbook_2.0.pdf`.
Сайт должен быть «живым, не компьютерным». Тон: конкретно, честно, тепло. Не выдумывать факты о школе (сертификаты, результаты, отзывы) — только с подтверждения владельца.

## Решения владельца

- Скидка −10% на первый пакет, если оформить в течение 3 дней после пробного.
- Приведи друга: 2 бесплатных занятия при покупке нового пакета.
- Смена преподавателя: подбираем другого, оставшиеся занятия пакета переходят к нему; первое занятие с новым — обычный урок из пакета, не пробное.
- Не писать C2/DELE/CAE у преподавателей — таких сертификатов нет. «Уровень подтверждён документами».
- Зарплата в вакансиях — «по результатам собеседования».
- Без отдельных страниц преподавателей и отзывов; карточки преподавателей — лентой.
- Данные кабинета — своя база на сервере в РФ (152-ФЗ, есть несовершеннолетние).
